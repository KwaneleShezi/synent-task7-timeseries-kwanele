# Task 7 - Time Series Analysis

## Problem Statement
Analyze stock price data to identify trends, seasonality patterns.

## Dataset
- Source: Kaggle
- Stock: Tesla (TSLA) Historical Price Data

## Approach
1. Loaded and cleaned historical stock data
2. Trend analysis using closing price and moving averages (30-day, 90-day)
3. Seasonality detection via time series decomposition
4. Volume and daily return analysis


## Results
- Identified long-term upward/downward trends
- Detected seasonal patterns in monthly data
- Measured average daily return and volatility
